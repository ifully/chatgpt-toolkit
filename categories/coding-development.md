# Kod geliştirme ve test

Bu sayfadaki depolar birer öneri ve kaynak bağlantısıdır; ChatGPT Web içinde otomatik yüklenmiş sayılmazlar.

| Öncelik | Kaynak | Kullanım | Çalıştırma biçimi |
|---|---|---|---|
| 1 | [playwright](https://github.com/microsoft/playwright) | Web arayüzü uçtan uca testleri. | `browser-runtime` |
| 1 | [playwright-mcp](https://github.com/microsoft/playwright-mcp) | Tarayıcı kontrolünü uygun MCP istemcisine açma. | `mcp-server` |
| 1 | [pytest](https://github.com/pytest-dev/pytest) | Tekrarlanabilir birim ve entegrasyon testleri. | `python-package` |
| 1 | [ruff](https://github.com/astral-sh/ruff) | Python statik kod denetimi ve biçimlendirme. | `cli` |
| 1 | [uv](https://github.com/astral-sh/uv) | Python paketleri ve izole çalışma ortamlarını yönetme. | `cli` |
| 2 | [pre-commit](https://github.com/pre-commit/pre-commit) | Commit öncesi otomatik doğrulamalar. | `cli` |
| 2 | [pydantic](https://github.com/pydantic/pydantic) | Python veri şeması ve girdi doğrulama. | `python-package` |
| 2 | [woocommerce](https://github.com/woocommerce/woocommerce) | WooCommerce eklentileri, API ve uyumluluk incelemesi. | `reference` |
| 2 | [wordpress-develop](https://github.com/WordPress/wordpress-develop) | WordPress çekirdeği ile uyumluluk ve kaynak incelemesi. | `reference` |

## Uygulama ölçütü

Araç seçerken güncel lisans, sürüm, bağımlılık, platform uyumu ve erişim yetkisini teyit edin. `tools.yaml` dosyasındaki yürütme sınıfları, kurulumun gerçekleştiğini göstermez.

## Görev istemi

> `Kod geliştirme ve test alanındaki bir görev için bu kategorideki adayları karşılaştır; mevcut çalışma ortamında kullanılabilenleri doğrula; kaynak ve sınırlılıkları bildir.`
